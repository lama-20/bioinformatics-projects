## 📂 Featured Projects

### 🧬 E. coli Variant Calling Analysis
Variant calling workflow using **Snippy** and **bcftools** for detecting SNPs and INDELs from whole genome sequencing data.

**Highlights**
- ✅ Variant Calling (SNPs & INDELs)
- ✅ Quality Filtering
- ✅ Python-based Data Analysis
- ✅ Data Visualization of Variant Statistics


---

### 🧬 DNA Sequence Analyzer (Python & Biopython)
A bioinformatics application for analyzing DNA sequences from FASTA files.

**Features**
- 🧮 GC Content Calculation
- 🔎 ATG Start Codon Detection
- 📖 Open Reading Frame (ORF) Detection
- 🧬 DNA → Protein Translation
- 📄 FASTA Parsing using Biopython

### 🩺 DiaCheck — Diabetes Risk Prediction App
`Machine Learning` `Data Science` `Deployment`

A machine learning web application that predicts diabetes risk based on patient medical data (glucose, BMI, insulin, age, etc.), built on the Pima Indians Diabetes dataset.

**Highlights**
- 📊 Exploratory Data Analysis (EDA)
- 🌲 Random Forest Classification Model
- 🚀 Deployed as an interactive web app using Streamlit
- 🎨 Custom UI design with real-time prediction
